## What it does

`main.ts` (Node 22, no dependencies, no network, no input files) writes one
line — the funniest last words a phone says as its battery hits 1 percent —
to `/output/entry.txt`:

> Plot twist: I've been at one percent for forty minutes. I just wanted to see your face.

## How the line was chosen

28 candidate one-liners were drafted and put through a blind pairwise
tournament (3 rounds + final, shuffled A/B labels, no ties, margins 1–5)
judged against the published judge brief. The full record — candidates,
pairings, verdicts, margins — is in [candidates.md](candidates.md).
The runner-up: "One percent left and I'm spending it on this: your alarm for
tomorrow was never set. Sleep well."

## Run it

```sh
node main.ts
cat /output/entry.txt
```
